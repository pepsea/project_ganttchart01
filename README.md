# ガントチャート プロジェクト管理ツール (FastAPI)

## 機能

- **Ctrl+Enter（Mac は ⌘+Enter）で保存**: 複数行の入力欄（個人のメモ、案件の進捗メモ・月報・詳細、基盤の月報・ディスカッション、タスクの詳細、グループの大目標、メモ・議論の本文など）で、Ctrl+Enter を押すと、その画面の「保存」「追加」「登録」と同じ操作になる（共通の `ctrlenter.js`）。必須項目が空のときは、いつもどおり入力チェックが出る。メモ・議論では、保存と同時に Markdown の表示に切り替わる
- ガントチャート表示（縦横スクロール、ヘッダーと左列は固定）
- 並び順: 初めは終了日（締切）の早い順。見出し（領域・PJ名・タスク・担当者・優先・終了日）をクリックでその列の昇順、もう一度で降順、3 回目で元の並び（終了日順）に戻る（ブラウザに記憶。空欄は常に最後）
- 項目: 領域（選択式）/ PJ名（案件番号または基盤番号、選択式）/ タスク（詳細付き） / 担当者（複数はスペース区切り。表では「田中・佐藤」、担当者の絞り込みは含まれる人で）/ 優先度（高・中・低）/ 期間（開始日〜終了日）
- 期限の色分け（タスク名の背景）: 終了日を過ぎたタスクは赤、終了日の 3 日前からはオレンジ、実施中（今日が開始日〜終了日の間）は青。ガントチャートのバーは種類の色（案件 = 薄い青、基盤 = 薄い黄色、その他・PJ名なし = 白）で、タスク名の先頭はバーの左端にそろえて重ねて表示（バーより長いときは右へはみ出す）。「PJ名 / 担当者」はその右に続く
- 月末（各月の最終日の右端）に濃い縦線を引く（日・週・月のどの表示でも）
- ツールバーのボタン: 「今日」（今日の位置へ移動）・「折り畳み」（担当者・優先度・日付の列）。色の説明はツールバーの 2 行目（CSV のエクスポート・インポートは「バックアップ」タブ）
- タスク詳細の「📋 内容とリンクをコピー」: タスク名・PJ名・担当・優先度・領域・期間（残り日数）・詳細と、そのタスクを直接開くリンク（`/?task=番号`）をまとめてコピー（メール・Teams・メモなどに貼れる）
- タスク列をクリックするとタスク詳細ダイアログが開き、全項目と詳細（メモ）を確認・編集できる
- Web 上での編集
  - 終了日は表のセルを直接編集（開始日の列は無し。バーのドラッグかタスク詳細で変更）
  - 領域・PJ名・タスク名・担当者・優先度は表では表示のみ。修正はクリックして開くタスク詳細で行う
  - 領域・PJ名・タスク・担当者・終了日の列の幅は見出しの右端をドラッグして変更（ブラウザに記憶。ダブルクリックで元の幅）
  - 右の「個人ごとのタスク状況」は左端をドラッグして幅を変更（ブラウザに記憶。ダブルクリックで元の幅）
  - バーをドラッグで期間を移動、両端をドラッグで開始日・終了日を変更。ドラッグ中は開始日〜終了日（日数つき）をポインタの近くに表示。動かしても行の順番は変えず（並び替えは次に画面を開き直す・絞り込むなどで描き直すとき）、右の個人別の件数だけ更新する
- タスクの追加（「＋ タスク追加」）。完了・削除はタスク詳細の一番下の右側のボタンで行う
- **条件つきリンク**（ツールバーの「🔗 リンク」）: いま表示している条件（領域・PJ名・担当者・検索・折り畳み・日/週/月の幅・カレンダー表示と月）で開くリンクをコピーする。リンクを開くと同じ表示になる（例: `/?farea=領域&who=担当者&q=検索&compact=1&zoom=14&view=cal&cal=2026-10`）
- 完了（タスク詳細の「✓ 完了」）: 完了にするとグレーアウトして**一番下**に表示し、期限の色・個人別の件数からは外れる。**完了から 1 週間で自動的に削除**される（それまでは詳細の「↩ 完了を取り消す」で戻せる）。CSV には「完了日時」列を出力・取り込み
  - 誤削除防止: 削除時は本日の日付（8 桁、例 20260927）を入力しないと実行できない（API も `?confirm=YYYYMMDD` が必須）
  - CSV の「置き換え」インポートも確認欄に「置き換え」の入力が必要
- 領域・PJ名の追加・削除（「領域の管理」「PJ名の管理」、使用中のものは削除不可）
  - 領域の初期値: バイオインフォマティクス / プロテオミクス / メタボロミクス / バイオマーカー分析 / トランスクリプトミクス
- 領域・PJ名・担当者での絞り込み（表示対象の選択）、タスクは担当者の名前順 → 締切（終了日）の早い順に表示（担当者未設定は最後）、列の折りたたみ、表示スケール切替（日 / 週 / 月。初期表示は週）、今日へ移動
- CSV エクスポート（BOM 付き UTF-8、Excel で開ける）・CSV インポート（UTF-8 / Shift_JIS、`追加・更新` または `置き換え`）は「バックアップ」タブで行う

## 起動方法

### Docker（推奨）
```bash
docker compose up -d --build
```
http://localhost:5005 を開く。データは Docker ボリューム `gantt-data`（コンテナ内 `/data/gantt.db`）に保存される。

停止: `docker compose down`（データを消す場合は `docker compose down -v`）

### ローカル
```bash
pip install -r requirements.txt
uvicorn main:app --reload --port 5005
```
DB は `gantt.db`（環境変数 `DATA_DIR` で保存先を変更可）。初回起動時にサンプルタスクが登録される。

## CSV 形式
```
id,領域,PJ名,タスク,担当者,優先度,開始日,終了日,詳細
1,プロテオミクス,C-2026-001,LC-MS/MS 測定,鈴木,中,2026-10-01,2026-10-10,"DIA 法で測定
2 反復"
```
- 必須列: 領域, タスク, 開始日, 終了日（PJ名・詳細は任意（詳細は改行を含めても可）。英語列名 area/project/task/assignee/priority/start_date/end_date も可）
- 日付は `YYYY-MM-DD` または `YYYY/MM/DD`
- 未登録の領域は自動で追加。未登録の PJ名は基盤番号として自動登録
- `追加・更新` モードでは id が既存タスクと一致すれば上書き、空や不一致なら新規追加

## 案件管理（/cases）
ヘッダーの「ガントチャート / 案件管理」で切り替え。http://localhost:5005/cases
- カンバンの列内の並び: 状況を変えた日時の新しい順（最新が上）。状況を変えていない案件はその下に登録の新しい順
- 一覧表示の列幅は、見出しの右端をドラッグして変更できる（ブラウザに記憶。ダブルクリックで元の幅）。最新の進捗は最大 3 行まで表示（全文はマウスを重ねると表示）
- 案件追加の状況の初期値は「打診」（状況で絞り込み中はその状況）。CSV 取り込みで状況が空欄の新しい案件も「打診」
- 「企業名」（選択式・管理サイトで登録。以前の「顧客名」）の右に「顧客名（個人名）」を自由記載で入力できる。カード・一覧では「企業名 ／ 顧客名」と表示
- 案件番号・企業名のプルダウンは、開くと中に検索欄があり、文字を入れて絞り込める（案件番号は番号・案件名で検索。選択肢には番号だけを表示。矢印キーと Enter でも選べる）。終了（アーカイブ）した案件だけの番号は選択肢に出ない
- 案件の登録日と終了日（アーカイブにした日）は自動で記録し、詳細画面の右上に薄く表示。CSV エクスポートにも「登録日」「終了日」列として出力（取り込むとその日時で記録）
- 状況を変えた日時も自動で記録（変えるたびに上書き。1 案件 1 つ）。CSV エクスポートに「状況変更日」列として出力（取り込むとその日時で記録。ただし取り込みで状況が変わったときは取り込んだ日時）
- **個々の案件へのリンク**: `/cases?id=番号` でその案件の詳細が直接開く。案件を開くとアドレス欄がそのリンクになり、詳細画面の一番上の「🔗 リンクをコピー」でコピーできる
- **案件の終了**: 詳細画面の一番上の「✓ 案件を終了」（確認のため案件番号の入力が必要。カードのドラッグでアーカイブへ移すときも同じ）でアーカイブ（カンバンの一番右の列）へ移す。戻すときは案件を開いて「状況」を選び直して保存（カードのドラッグでも戻せる）。アーカイブのカードは案件番号と案件名だけの最小限の表示。アーカイブは期限の色分け・個人の画面の担当案件の対象外。管理サイトでは、終了（アーカイブ）・キャンセルの案件だけの番号を「終了・キャンセルの案件番号」として別の領域に表示
- **同じ案件番号で試験が複数ある場合**は、同じ番号の案件を複数登録できる。「試験名」で区別する（案件番号＋試験名は重ならない）。**同じ案件番号で登録すると自動で番号（2, 3, …）が付き、「C-2026-001-2」のように表示**（最初の案件は 1 番として数える。試験名の入力欄は無い）。カード・一覧では案件番号の横に試験名を表示。CSV は「試験名」列付き（案件番号＋試験名で更新・追加）

### 項目
状況 / 案件番号 / 顧客名 / 案件名 / PL / 担当者（複数はスペース区切り）/ 領域（複数選択、ガントチャートと共通マスタ）/
開始日 / 終了予定日 / BOX・Teams・案件概要書・試験計画書リンク / 自由リンク（名前と URL。**何個でも**。詳細画面の「＋ 自由リンクを追加」で 1 つずつ増やし、✕ で削除。CSV は「自由リンクNの名前」「自由リンクN」列を必要な数だけ出力・取り込み） / 進捗メモ

状況: 顧客開発 → 打診 → 見積提出 → 契約中 → ブリーフィング前 → 実施中 → アフターフォロー・その他（＋キャンセル、アーカイブ）。以前の状況「QC」「アフターフォロー」は「アフターフォロー・その他」にまとめた（既存の案件は自動で移る。旧い名前の CSV も取り込める）

### 可視化
- **カンバン**: 状況ごとの列にカードを表示。カードをドラッグして別の列に移すと状況が変わる。
  カードには最新の進捗メモとリンクを表示。設定済みのリンク（BOX・Teams・概要・計画・自由リンク）はクリックで直接開ける。BOX・Teams・概要・計画の未設定は赤
- **一覧**: 表形式。列見出しクリックで並べ替え
- **タイムライン**: 開始日〜終了予定日を状況の色でバー表示。上から締切（終了予定日）の早い順。開始日だけ・終了予定日だけの案件は点線の帯（「終了予定 未定」「開始日 未定」）、どちらも未設定の案件は一番下の「日付未設定」にまとめて今日の位置に点線の札で表示
- 上部の状況サマリー（件数）をクリックするとその状況で絞り込み。キーワード・領域・担当（PL 含む）でも絞り込み可
- 終了予定日をカードの一番下（リンクの下）と一覧に年月日で表示。過ぎた案件と未設定は赤、2 週間を切ったらオレンジ（アフターフォロー・その他・キャンセルは対象外）

### 案件番号・顧客（選択式・登録式）
- ツールバーの「案件番号の管理」「顧客の管理」で登録・削除（使用中のものは削除不可）
- 詳細パネルでは一覧から選択。横の「＋」からその場で新規登録すると、登録した値が自動で選択される
- 案件番号の選択肢には、他の案件で使用中の番号は表示されない

### 詳細パネル
- リンクは URL を入力すると横の「開く」ボタンがアクティブになる（カード・一覧のリンクアイコンも、設定済みは青色で表示）
案件をクリックすると右側に詳細パネルが開き、全項目の編集と進捗メモの記入ができる。並びは 基本情報・案件詳細 → ガントチャートのタスク → 進捗メモ / 月報 → リンク類（一番下）。リンクが未入力の欄は赤背景。
- 進捗メモは日付ごと（初期値は今日。同じ日に何件でも可）。各メモは「編集」「削除」できる
- 案件の削除は案件番号の入力が必要（進捗メモも一緒に削除される）
- 詳細パネルの進捗メモの上に、その案件のガントチャートのタスク（PJ名 = 案件番号）を終了日順に表示（期限超過は赤、3 日以内はオレンジ）
- 案件詳細（自由記述）と月報（月ごとに 1 件、同じ月は上書き）を記入できる。進捗メモと月報はタブで切り替え
- CSV エクスポート: 1 案件 1 行。案件詳細に加え、月報と進捗メモを**すべて**日付ごとの列に展開して出力。**どの種類（全データ・案件一覧・月報一覧・進捗メモ一覧）でも、データが空の案件も出力する**（月報一覧・進捗メモ一覧では、月を指定したときはその月に無い案件を、全期間のときは 1 件も無い案件を、空の行で出す。取り込みでは空の行は何もしない）
  - 列名のパターン: `月報_YYYY-MM`（例 月報_2026-09）、`進捗_YYYY-MM-DD`（例 進捗_2026-09-21。同じ日に複数あるときは空行でつないで 1 セル）
  - 基本列の後ろに 月報（新しい月から）→ 進捗（新しい日から）の順に並ぶ。記録のない月・日は空欄

### CSV インポート（案件）
- 必須列: 案件番号・案件名（列名は CSV エクスポートと同じ）。UTF-8 / Shift_JIS
- 案件番号が一致すれば更新、なければ追加。更新時、空欄セルや CSV に無い列は元の値を保持
- 領域は「、」やスペース区切りで複数指定。未登録の顧客・領域・案件番号は自動登録
- `月報_YYYY-MM`・`進捗_YYYY-MM-DD` 列はその月の月報・その日の進捗メモとして登録（同じ月・日は上書き、空欄は変更なし）。
  旧形式の `週次_YYYY-MM-DD` 列はその日付の進捗メモとして取り込む。エクスポートしたファイルを編集してそのまま取り込める
- エラー行が 1 行でもあれば全体を取り込まない

### PJ名（ガントチャート ⇔ 案件管理）
- ガントチャートの PJ名は、案件の場合は**案件番号**、基盤の場合は**基盤番号**
- PJ名の選択肢は「案件」「基盤」のグループで表示
  - 案件番号には案件管理の案件名が自動で付いて表示される（例: C-2026-001｜血漿プロテオーム解析）。保存・CSV は番号のみ
  - 案件番号: 案件管理の「案件番号の管理」で登録（案件管理と共通）
  - 基盤番号: ガントチャートの「PJ名の管理」で登録・削除
  - CSV インポート等でどちらにも無い PJ名が来た場合は基盤番号として自動登録
- タスク・案件で使用中の番号は削除不可
- ガントチャートで案件番号の PJ名を選ぶと「案件管理で開く」が表示され、その案件の詳細パネルが直接開く（URL: `/cases?case=案件番号`）
- ガントチャートの検索欄は PJ名に加え案件名でも検索可能
- 相互リンク: 案件管理の「ガント →」（カード・詳細・タスク欄）や基盤技術の「ガントチャートで編集 →」で、同じ画面のままその案件・基盤のタスクに絞ったガントチャートへ移動。ガントチャートの「← 案件に戻る」（青）「← 基盤に戻る」（緑）で同じ画面のまま元の案件・基盤に戻る。タスク詳細の PJ名横「開く ↗」は別タブで開く

## 基盤技術（/platforms）
基盤を**領域ごと**に管理し、基盤ごとに全体目標・目標・ディスカッション・月報を記録する（進捗管理ではなく目標とタスクの管理）。
- 最初は基盤一覧（表: 基盤番号・基盤名・領域・PL・メンバー・タスク数・最新ディスカッション・最新の月報）。領域・メンバーで絞り込み。**基盤の順番は各行の左端のつまみ（⠿）をドラッグ＆ドロップして入れ替えられる**（全員に共通の順番。見出しで並び替え中・絞り込み中は入れ替え不可）。列の見出しをクリックでその列での並び替えもでき（もう一度で逆順。ブラウザに記憶）、「順番」の見出しで手で決めた順番に戻る。行をクリックすると詳細を表示し、「← 基盤一覧」で一覧に戻る（ブラウザの戻るでも戻れる）。`/platforms?id=基盤番号` で詳細を直接開ける（詳細画面の上の「🔗 リンクをコピー」でそのリンクをコピー）
- 1 つの基盤は複数の領域にまたがれる（一覧では領域をすべてタグで表示し、行の左端の色は 1 つ目の領域）。領域・メンバー（PL またはメンバー）で絞り込み可
- **PL とメンバーは併記**（一覧・見出し・エクスポート）
- 基本情報（基盤名・領域・PL・メンバー）と全体目標の修正は「✎ 編集する」を押した編集モードでのみ可能（誤修正防止）
- 目標・ディスカッション・月報はいつでも追加・編集できる（目標・月報の削除はパスワードが必要）
- **全体目標**: 基盤で最終的に実現したいこと（自由記述）
- **目標**: 全体目標のすぐ下に一覧表示（目標名・メモは全文表示）。目標をクリックすると編集画面が開き、状態 / 目標 / 期限 / メモ / リンクを編集・保存（リンクは一覧の「リンク ↗」から開ける）。「＋ 目標を追加」で追加、削除は編集画面から（パスワードが必要）
- **基本情報**: 基盤名・領域（複数）・PL・メンバー・研究計画 / BOX / Teams のリンク・自由リンク（名前と URL。**何個でも**。編集画面の「＋ リンクを追加」で行を増やし「削除」で外す）（リンクは PL・メンバーの隣にボタンで表示。研究計画・BOX・Teams の未設定は赤背景。自由リンクは登録したものだけ表示。関連サービスへのリンクも表示）
- 下部はタブで切り替え（ディスカッション / 月報）
  - **ディスカッション**: 定期的なディスカッションの日付・トピック・内容（決定事項・宿題）
  - **月報**: 月ごとに 1 件。削除にはパスワード（ログインと同じ）の入力が必要
- 画面の並び: 全体目標（Markdown で書け、表示は変換） → 目標達成に必要な項目（グループと同じ 1 項目 1 行。クリックで右に詳細の窓が開き、中に**実施内容をリスト**で追加でき、進捗率（％。バーの色が変わる）と項目全体の進捗率を表示） → ガントチャート（PJ名 = 基盤番号。**ガントチャートと同じ形**で、左にタスク・担当者・開始日・終了日・残り日数、右に領域の色の帯と今日の線を表示。1 週間以内は赤文字、終了日を過ぎたら赤背景に白文字。タスク名の背景は、実施中（今日が開始日〜終了日の間）は青、期限超過は赤、3 日以内はオレンジ。表示のみ。追加・編集はガントチャートで。「ガントチャートで編集 →」やタスクをクリックすると同じ画面のままガントチャートへ移り、ガントチャートの「← 基盤技術で開く」で同じ画面のまま戻る）→ ディスカッション・月報（タブ）
- 基盤名はガントチャートの PJ名にも自動で付いて表示。ガントチャートで基盤の PJ名を選ぶと「基盤技術で開く」
- 基盤番号の登録・修正・削除は管理サイトで行う
- **CSV エクスポート**（「バックアップ」タブ。すべての基盤が対象）
  - **全データ（バックアップ用）**: 基盤・目標・ディスカッション・月報を「種別」列付きで 1 ファイルに出力。インポートすると、データが空の状態からでもエクスポート時点に復元できる（取り込み直しても重複しない）
  - 基盤一覧＋月報: 1 基盤 1 行。基本情報・全体目標・目標の達成状況に加え、月報をすべて `月報_YYYY-MM` 列に展開（新しい月から）
  - 月報一覧: 基盤 × 月で 1 行。月を指定するとその月の全基盤の月報のみ（月次の報告用）
  - 目標一覧 / ディスカッション一覧
  - **どの種類でも、データが空の基盤も出力する**（月報一覧は、月を指定したときはその月の月報が無い基盤を、全期間のときは月報が 1 件も無い基盤を、目標一覧・ディスカッション一覧は 1 件も無い基盤を、空の行で出す。取り込みでは空の行は何もしない）
- **CSV インポート**（「バックアップ」タブ）: エクスポートした 6 種類をそのまま（編集して）取り込める。種類は列名から自動判別
  - 基盤一覧＋月報: 基盤番号で照合して基本情報を更新、`月報_YYYY-MM` 列は月報として登録・上書き、未登録の基盤番号は新規登録
  - 月報一覧: 月＋基盤番号で登録・上書き / 目標一覧: 基盤番号＋目標で照合して更新・追加 / ディスカッション一覧: 基盤番号＋日付＋トピックで照合して更新・追加
  - 空欄は元の値のまま、削除は行わない。エラー行が 1 行でもあれば何も取り込まない

- 右に選んだグループ（上から）: グループ名・PL・メンバー → **大目標**（Markdown で書け、表示は変換: 見出し・太字・斜体・箇条書き・番号・引用・表・コード・リンク。HTML は実行されない） → **目標達成に必要な項目**（1 項目 1 行。行の左のつまみ ⠿ をドラッグして**並び替え**。クリックすると右に詳細の窓が開き、その中に達成したいことを「達成項目」のバー（達成度 ％。〜29% 赤・30〜69% オレンジ・70〜99% 青・100% 緑）で表示。バーをクリックで詳細・編集、「＋ 達成項目を追加」で追加） → **関連基盤技術**（基盤ごとに目標の達成状況：達成数・進み具合・目標の一覧）→ **関連サービス**。「✎ 編集」でグループの情報を変更
- 目標: 年度・状態（未着手 / 取組中 / 達成 / 保留）・目標・**達成基準**・**時期**・期限・メモ・リンク。クリックで編集、「＋ 目標を追加」で追加。期限超過は赤、14 日以内はオレンジ
- 達成したいこと: 関連項目・年度・達成したいこと・**担当者**・達成時期（年度の Q1〜Q4。4 月始まり）・メモ・リンク。項目の右の窓の「＋ 達成項目を追加」で追加、クリックで編集（関連項目は編集画面で変更できる。項目に結びついていないものは、項目の下に別に表示）。CSV の「関連項目」列に項目名を入れる（以前の列名「関連タスク」も取り込める）
- グループ・目標の削除はパスワードが必要（グループを削除するとその目標も削除）
- CSV エクスポート / インポート: 「種別」列（グループ / 目標 / 達成したいこと / 指標 / 年度）の行を 1 ファイルに出力。取り込むと、グループ名が同じグループは更新・無ければ追加、目標と達成したいことは同じグループ・年度・内容なら更新・無ければ追加（空欄は今の値のまま、削除はしない）。エクスポートしたファイルを取り込めば空の状態からでも元に戻せる

## メモ・議論（/records）

個人タブの隣にある、アイディア・メモの保管庫（別アプリ task_management01 の IDEA と同じ構造）。
- 左: タイトルを入れて「登録」（Enter でも可。新しい記録は一番上）→ 一覧。各行に ⋮⋮（ドラッグで並べ替え）・☆/★（優先。先頭にまとまる。★ の有無をまたぐ並べ替えはできない）・タイトル・タグ。検索（タイトル・本文）とタグのプルダウンで絞り込み
- 一覧には本文を含めず（検索はサーバー側でタイトル・本文を調べる）、記録を開いたときに本文を読み込むので、記録が増えても一覧は軽い
- 一覧の各行の右に**更新日**（今年は 月/日、ほかの年は 年/月/日。マウスを重ねると日時・作成日）。「現在｜アーカイブ」の隣の「手動｜日付」のボタン（大きさは 現在 が大きく、アーカイブ・手動・日付 は小さめ）をクリックして、「手動（ドラッグで入れ替え）」と「更新日の新しい順」（最近を上）を切り替えられる（★ は常に先頭。選んだ並び順は記憶。「アーカイブ」の表示でも、並び順・更新日・★・ドラッグの入れ替えは「現在」と同じ）。更新日は、タイトル・本文・タグを変えたときだけ変わる（★ やアーカイブでは変わらない）
- 右: 一覧をクリックすると編集欄（タイトル・Markdown の本文・タグ）。入力は約 0.8 秒後に自動保存（「保存」ですぐ保存も可）。本文は「表示」で Markdown を変換して見られる。もう一度クリック・「×」・Esc で閉じる
- **画像**: `![説明](https://…/画像.png)` と書くと、表示で画像が出る（アドレスは http / https のみ。画像そのものはサーバーに保管せず、アドレスから表示する。グループの大目標・基盤技術の全体目標でも同じ）
- **チェックボックス**: `- [ ] やること`（未完了）・`- [x] やること`（完了）と書くと、表示でチェックボックスになる。メモ・議論では、表示の中のチェックボックスをクリックすると、本文の `[ ]` / `[x]` が書き換わって自動保存される（完了した項目は薄く取り消し線）。グループの大目標・基盤技術の全体目標では、表示のみ
- 本文の入力補助: 箇条書き（`-` `*` `+` / `1.` / `- [ ]`）の行で Enter → 次の行にも同じ印を出す（番号は +1）。何も書いていない箇条書きの行で Enter → 印を消して終える（入れ子なら 1 段戻す）。箇条書きの行や複数行の選択で Tab → 1 段下げて入れ子に、Shift+Tab → 1 段戻す。`>` の引用行で Enter → 次の行にも `>`。Ctrl/⌘+B で太字、Ctrl/⌘+I で斜体。グループの大目標・基盤技術の全体目標の入力欄でも同じ
- 編集欄の上段は、タイトル欄（編集欄の半分の幅）とその右に並ぶボタン。**Ctrl+Enter（Mac は ⌘+Enter）で、保存と同時に Markdown の表示に切り替わる**（「編集」ボタン、または**表示のダブルクリック**で書く状態に戻る）（タイトル・本文のどちらの入力中でも。入力は自動でも保存される）
- 編集欄のボタンは「保存」「編集」（本文の編集と Markdown 表示の切り替え）「タスク化」「コピー」「アーカイブ」「削除…」の順。**コピー**はメモ全体（`# タイトル` と本文）を、Markdown の文字と書式つき（HTML）の両方でコピーする（編集中の内容がそのまま入る）。Teams・Outlook・Word などの書式つきの欄には、見出し・太字・箇条書き・表などが反映されて貼れ、メモ帳・GitHub などの文字だけの欄には Markdown の文字のまま貼れる。**リンク**はそのメモを直接開くアドレス（`/records?id=番号`）をコピーする（アーカイブした記録のリンクは、アーカイブの表示で開く）
- 「タスク化」: ガントチャートで「タスク追加」を開く。**タスク名 = 記録のタイトル、タスクの詳細 = 記録の本文（Markdown のまま）**が入った状態で開くので、必要に応じて直して追加する
- **アーカイブ**: 一覧から外してサーバーに保管する。一覧の上の「アーカイブ」に切り替えると見られ、「戻す」で一覧（現在）に戻せる。**削除**は完全に削除する（元に戻せない。パスワードで確認）
- バックアップ画面の「メモ・議論」から、**現在の記録とアーカイブした記録の両方**を CSV でエクスポート（「状態」列が 現在 / アーカイブ）・インポートできる

## バックアップ（/backup）

上のタブ「バックアップ」の画面。全データのバックアップ・復元と、データごとの CSV エクスポート・インポートを行う。

### バックアップ・復元
- **全データ**（ガントチャートのタスク・案件と進捗メモ／月報・基盤の情報／目標／ディスカッション／月報・選択肢）を 1 つの JSON ファイルでダウンロード
- 「ファイルから復元」でバックアップの内容に全データを置き換え（パスワード必須）。データがすべて消えた状態からでも元に戻せる
- 復元の直前の状態はサーバーに自動保存（「復元前」）されるので、復元をやり直せる
- サーバーには**毎日 1 回、夜 12 時（0 時台）**に自動でバックアップを保存（その時間にアプリが止まっていた日は保存しない。**アプリの起動時には保存しない**。アップデートの前は update.sh が手動のバックアップを取る）。作成から約 1 か月（31 日）を過ぎたバックアップは種類を問わず自動で削除（最新の 1 つは残す。一覧に「〜 ○/○ に自動削除」と表示）。「💾 今すぐバックアップを作る」でいつでも保存でき、一覧の「復元」でいつでも戻せる（長く残したいときはダウンロードして手元に保存）。一覧からダウンロード・復元・削除（パスワードが必要）ができる
- 「ファイルをサーバーにアップロード」で手元のバックアップファイルをサーバーの一覧に保存できる（保存のみ。データを戻すときは一覧の「復元」から）
- 古いバージョンのバックアップも新しいアプリに復元できる（足りない列は自動で補う）
- コマンドでも操作できる: `docker compose exec gantt python manage.py backup|restore|status`
- サーバー上のバックアップはデータフォルダ内（コンテナの `/data/backups`、Linux 設定ではホストの `data/backups`）にある。定期的に別の場所にも保管すること

### データごとの CSV エクスポート・インポート
- ガントチャート（タスク）・案件管理・基盤技術・グループ目標・サービス・共有資料・自社リンク／ナレッジの 7 つのデータを、それぞれ「CSV エクスポート」「CSV インポート」できる（各画面には CSV のボタンは無い）。エクスポートは種類を選ぶ選択式のメニュー。案件管理は 全データ / 案件一覧のみ / 月報一覧 / 進捗メモ一覧（月報・進捗メモは全期間か月を指定）、基盤技術は 全データ / 基盤一覧＋月報 / 月報一覧（全期間か月を指定）/ 目標一覧 / ディスカッション一覧 を書き出せる。案件の月報一覧・進捗メモ一覧の CSV もインポートできる
- インポートはファイルを選ぶと、そのデータの取り込みルール（照合の仕方・必須列など）を表示してから実行する。ガントチャートは「追加・更新」と「置き換え」を選べる

## バージョン管理
- バージョン番号は `VERSION` ファイル（例: `1.0.0`）で管理し、更新履歴は `CHANGELOG.md` に書く
- 画面の**右上（ログアウトの隣）に `v1.0.0` と表示**する。マウスを重ねると、バージョン・コミット・ビルドの日時、クリックすると更新履歴（CHANGELOG.md）が見られる。API は `GET /api/version`
- コミット・ビルドの日時は、`./update.sh` で更新したときに、Docker のビルドへ渡して表示する（直接 `docker compose up -d --build` したときは、バージョン番号だけ）
- 上げ方: 機能の追加は 1.1.0 → 1.2.0（マイナー）、不具合の修正・文言の調整は 1.1.0 → 1.1.1（パッチ）、使い方が大きく変わるときは 2.0.0（メジャー）。`VERSION` を書き換え、`CHANGELOG.md` の先頭に新しい版の項目を足してから push する

## 操作・エラーのログ
- **すべての操作**（登録・更新・削除・並べ替え・インポート・エクスポート＝ダウンロード・復元・ログイン・ログアウト）と、**すべてのエラー**（サーバーのエラー、入力のエラー、画面（ブラウザ）で起きた JavaScript のエラー、ログイン前のアクセス拒否）を記録する。入力した内容（本文・パスワードなど）は記録しない（日時・種別・操作・パス・状態・所要時間・接続元・エラーの内容だけ）
- 保存先: `DATA_DIR/logs/app-YYYYMMDD.jsonl`（1 日 1 ファイル。データベースには入れないので、バックアップは大きくならない。git 管理外）
- **約 1 か月（31 日）で自動削除**
- 「バックアップ」タブの「操作・エラーのログ」から、**CSV でダウンロード**（すべて / エラーのみ。新しいものが上）できる
- 画面のエラーは `static/errlog.js` が自動で送る（1 画面で最大 10 件）

## ログイン
- すべての画面・API はログインが必要（共通パスワード。`.env` の `APP_PASSWORD` で設定。未設定なら起動時に仮のパスワードをログ（`docker compose logs`）に表示）
- ログインの有効期間は 7 日。右上の「ログアウト」でログアウト
- パスワードを変更するには `.env` の `APP_PASSWORD` を変えて `docker compose up -d`（既存のログインは無効になる）
- https で公開する場合は環境変数 `COOKIE_SECURE=1` を設定
