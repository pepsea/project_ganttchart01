# ガントチャート プロジェクト管理ツール (FastAPI)

## 機能
- ガントチャート表示（縦横スクロール、ヘッダーと左列は固定）
- 項目: 領域（選択式）/ PJ名（案件番号または基盤番号、選択式）/ タスク（詳細付き） / 担当者 / 優先度（高・中・低）/ 期間（開始日〜終了日）
- 期限の色分け（タスク名の背景）: 終了日を過ぎたタスクは赤、終了日の 3 日前からはオレンジ。ガントチャートのバーは領域の色
- タスク列をクリックするとタスク詳細ダイアログが開き、全項目と詳細（メモ）を確認・編集できる
- Web 上での編集
  - 優先度・開始日・終了日は表のセルを直接編集
  - 領域・PJ名・タスク名・担当者は表では表示のみ。修正はクリックして開くタスク詳細で行う
  - PJ名・タスク列の幅は見出しの右端をドラッグして変更（ブラウザに記憶。ダブルクリックで元の幅）
  - 開始日はカレンダーアイコンのみ、終了日は日付を表示（クリックでカレンダー、ホバーで日付）
  - バーをドラッグで期間を移動、両端をドラッグで開始日・終了日を変更
- タスクの追加（「＋ タスク追加」）と削除（🗑）
  - 誤削除防止: 削除時は本日の日付（8 桁、例 20260927）を入力しないと実行できない（API も `?confirm=YYYYMMDD` が必須）
  - CSV の「置き換え」インポートも確認欄に「置き換え」の入力が必要
- 領域・PJ名の追加・削除（「領域の管理」「PJ名の管理」、使用中のものは削除不可）
  - 領域の初期値: バイオインフォマティクス / プロテオミクス / メタボロミクス / バイオマーカー分析 / トランスクリプトミクス
- 領域・PJ名・担当者での絞り込み（表示対象の選択）、タスクは担当者の名前順 → 締切（終了日）の早い順に表示（担当者未設定は最後）、列の折りたたみ、表示スケール切替（日 / 週 / 月）、今日へ移動
- CSV エクスポート（BOM 付き UTF-8、Excel で開ける）
- CSV インポート（UTF-8 / Shift_JIS、`追加・更新` または `置き換え`）

## 起動方法

### Docker（推奨）
```bash
docker compose up -d --build
```
http://localhost:5005 を開く。データは Docker ボリューム `gantt-data`（コンテナ内 `/data/gantt.db`）に保存される。

停止: `docker compose down`（データを消す場合は `docker compose down -v`）

### ローカル
```bash
pip install -r requirements.txt
uvicorn main:app --reload --port 5005
```
DB は `gantt.db`（環境変数 `DATA_DIR` で保存先を変更可）。初回起動時にサンプルタスクが登録される。

## CSV 形式
```
id,領域,PJ名,タスク,担当者,優先度,開始日,終了日,詳細
1,プロテオミクス,C-2026-001,LC-MS/MS 測定,鈴木,中,2026-10-01,2026-10-10,"DIA 法で測定
2 反復"
```
- 必須列: 領域, タスク, 開始日, 終了日（PJ名・詳細は任意（詳細は改行を含めても可）。英語列名 area/project/task/assignee/priority/start_date/end_date も可）
- 日付は `YYYY-MM-DD` または `YYYY/MM/DD`
- 未登録の領域は自動で追加。未登録の PJ名は基盤番号として自動登録
- `追加・更新` モードでは id が既存タスクと一致すれば上書き、空や不一致なら新規追加

## 案件管理（/cases）
ヘッダーの「ガントチャート / 案件管理」で切り替え。http://localhost:5005/cases

### 項目
状況 / 案件番号 / 顧客名 / 案件名 / PL / 担当者（複数はスペース区切り）/ 領域（複数選択、ガントチャートと共通マスタ）/
開始日 / 終了予定日 / BOX・Teams・案件概要書・試験計画書リンク / 週次進捗メモ

状況: 顧客開発 → 打診 → 見積提出 → 契約中 → ブリーフィング前 → 実施中 → QC → アフターフォロー（＋キャンセル）

### 可視化
- **カンバン**: 状況ごとの列にカードを表示。カードをドラッグして別の列に移すと状況が変わる。
  カードには最新の進捗メモと「今週未記入 / 今週記入済」バッジ（契約中〜アフターフォローが対象）を表示
- **一覧**: 表形式。列見出しクリックで並べ替え
- **タイムライン**: 開始日〜終了予定日を状況の色でバー表示（日付未設定の案件は対象外）
- 上部の状況サマリー（件数）をクリックするとその状況で絞り込み。キーワード・領域・担当（PL 含む）でも絞り込み可
- 終了予定日を過ぎた案件は赤、3 日以内はオレンジ（アフターフォロー・キャンセルは対象外）

### 案件番号・顧客（選択式・登録式）
- ツールバーの「案件番号の管理」「顧客の管理」で登録・削除（使用中のものは削除不可）
- 詳細パネルでは一覧から選択。横の「＋」からその場で新規登録すると、登録した値が自動で選択される
- 案件番号の選択肢には、他の案件で使用中の番号は表示されない

### 詳細パネル
- リンクは URL を入力すると横の「開く」ボタンがアクティブになる（カード・一覧のリンクアイコンも、設定済みは青色で表示）
案件をクリックすると右側に詳細パネルが開き、全項目の編集と週次進捗メモの記入ができる。
- 週次進捗メモは週（月曜始まり）ごとに 1 件。同じ週に再保存すると上書き。過去の週も選んで記入・編集できる
- 案件の削除は案件番号の入力が必要（進捗メモも一緒に削除される）
- 詳細パネルの一番下に、その案件のガントチャートのタスク（PJ名 = 案件番号）を終了日順に表示（期限超過は赤、3 日以内はオレンジ）
- 案件詳細（自由記述）と月報（月ごとに 1 件、同じ月は上書き）を記入できる。週次進捗メモと月報はタブで切り替え
- CSV エクスポート: 1 案件 1 行。案件詳細に加え、月報と週次進捗メモを**すべて**日付ごとの列に展開して出力
  - 列名のパターン: `月報_YYYY-MM`（例 月報_2026-09）、`週次_YYYY-MM-DD`（週の月曜日。例 週次_2026-09-21）
  - 基本列の後ろに 月報（新しい月から）→ 週次（新しい週から）の順に並ぶ。記録のない月・週は空欄

### CSV インポート（案件）
- 必須列: 案件番号・案件名（列名は CSV エクスポートと同じ）。UTF-8 / Shift_JIS
- 案件番号が一致すれば更新、なければ追加。更新時、空欄セルや CSV に無い列は元の値を保持
- 領域は「、」やスペース区切りで複数指定。未登録の顧客・領域・案件番号は自動登録
- `月報_YYYY-MM`・`週次_YYYY-MM-DD` 列はその月の月報・その週の週次進捗メモとして登録（同じ月・週は上書き、空欄は変更なし）。
  週次の日付は週の途中の日でもよい（その週の月曜日として扱う）。エクスポートしたファイルを編集してそのまま取り込める
- エラー行が 1 行でもあれば全体を取り込まない

### PJ名（ガントチャート ⇔ 案件管理）
- ガントチャートの PJ名は、案件の場合は**案件番号**、基盤の場合は**基盤番号**
- PJ名の選択肢は「案件」「基盤」のグループで表示
  - 案件番号には案件管理の案件名が自動で付いて表示される（例: C-2026-001｜血漿プロテオーム解析）。保存・CSV は番号のみ
  - 案件番号: 案件管理の「案件番号の管理」で登録（案件管理と共通）
  - 基盤番号: ガントチャートの「PJ名の管理」で登録・削除
  - CSV インポート等でどちらにも無い PJ名が来た場合は基盤番号として自動登録
- タスク・案件で使用中の番号は削除不可
- ガントチャートで案件番号の PJ名を選ぶと「案件管理で開く」が表示され、その案件の詳細パネルが直接開く（URL: `/cases?case=案件番号`）
- ガントチャートの検索欄は PJ名に加え案件名でも検索可能
- 相互リンク: ガントチャートのタスク詳細の PJ名横「開く ↗」で案件管理（案件番号）／基盤技術（基盤番号）へ、案件管理の案件番号横「ガント ↗」でその案件のタスクに絞ったガントチャートへ移動

## 基盤技術（/platforms）
基盤を**領域ごと**に管理し、基盤ごとに全体目標・目標・ディスカッション・月報を記録する（進捗管理ではなく目標とタスクの管理）。
- 1 つの基盤は複数の領域にまたがれる。左の一覧は領域ごとにグループ表示し、各基盤は 1 回だけ表示（1 つ目の領域のグループに表示し、2 つ目以降の領域はタグで表示）。領域・メンバー（PL またはメンバー）で絞り込み可
- **PL とメンバーは併記**（一覧・見出し・エクスポート）
- 基本情報（基盤名・領域・PL・メンバー）と全体目標の修正は「✎ 編集する」を押した編集モードでのみ可能（誤修正防止）
- 目標・ディスカッション・月報はいつでも追加・編集できる（目標・月報の削除はパスワードが必要）
- **全体目標**: 基盤で最終的に実現したいこと（自由記述）
- **目標**: 全体目標のすぐ下に一覧表示（目標名・メモは全文表示）。目標をクリックすると編集画面が開き、状態 / 目標 / 期限 / メモ / リンクを編集・保存（リンクは一覧の「リンク ↗」から開ける）。「＋ 目標を追加」で追加、削除は編集画面から（パスワードが必要）
- **基本情報**: 基盤名・領域（複数）・PL・メンバー・研究計画 / BOX / Teams のリンク（リンクは基盤名の下にボタンで表示。関連サービスへのリンクも表示）
- 下部はタブで切り替え（ディスカッション / 月報）
  - **ディスカッション**: 定期的なディスカッションの日付・トピック・内容（決定事項・宿題）
  - **月報**: 月ごとに 1 件。削除にはパスワード（ログインと同じ）の入力が必要
- 画面の並び: 全体目標 → 目標 → ガントチャートのタスク（PJ名 = 基盤番号。表示のみ、追加・編集はガントチャートで）→ ディスカッション・月報（タブ）
- 基盤名はガントチャートの PJ名にも自動で付いて表示。ガントチャートで基盤の PJ名を選ぶと「基盤技術で開く」
- 基盤番号の登録・修正・削除は管理サイトで行う
- **CSV エクスポート**（右上のメニュー。左の領域・メンバーの絞り込みを反映）
  - **全データ（バックアップ用）**: 基盤・目標・ディスカッション・月報を「種別」列付きで 1 ファイルに出力。インポートすると、データが空の状態からでもエクスポート時点に復元できる（取り込み直しても重複しない）
  - 基盤一覧＋月報: 1 基盤 1 行。基本情報・全体目標・目標の達成状況に加え、月報をすべて `月報_YYYY-MM` 列に展開（新しい月から）
  - 月報一覧: 基盤 × 月で 1 行。月を指定するとその月の全基盤の月報のみ（月次の報告用）
  - 目標一覧 / ディスカッション一覧
- **CSV インポート**（右上）: エクスポートした 5 種類をそのまま（編集して）取り込める。種類は列名から自動判別
  - 基盤一覧＋月報: 基盤番号で照合して基本情報を更新、`月報_YYYY-MM` 列は月報として登録・上書き、未登録の基盤番号は新規登録
  - 月報一覧: 月＋基盤番号で登録・上書き / 目標一覧: 基盤番号＋目標で照合して更新・追加 / ディスカッション一覧: 基盤番号＋日付＋トピックで照合して更新・追加
  - 空欄は元の値のまま、削除は行わない。エラー行が 1 行でもあれば何も取り込まない

## サービス（/services）
サービスメニュー。画面を左右に分け、**左 1/3 に主要サービスパッケージ**、**右 2/3 にサービス一覧**を表示する。
- 画面の一番上に**親リンク**（表示名と URL。✎ で設定・変更）
- 主要サービスパッケージ: パッケージ名・パッケージ資料（日）／（英）・BOX のリンク・関連サービス。
  関連サービスをクリックすると右側でそのサービスを開く。「＋ パッケージ追加」／「✎」で追加・編集、削除はパスワードが必要
- サービス一覧は上から順番（サービス番号順）に、1 サービスを 1 行で表示する。
- 1 行: サービス番号・サービス名・領域・タスクの有無（件数）・編集
- 行をクリックすると詳細を開閉: PL・担当者、リンク（BOX・サービス資料（日）・サービス資料（英））、関連する基盤技術（基盤技術へのリンク）、ゴール、課題、タスク
- タスクはガントチャートと連携: PJ名が関連する基盤番号のタスクを表示（表示のみ。PJ名をクリックするとその PJ名で絞り込んだガントチャートを開き、そこで編集）
- 「＋ サービス追加」／各行の「✎ 編集」で追加・編集。削除は編集画面から（パスワードが必要）
- キーワード（サービス名・番号・基盤番号）・領域・メンバー（PL または担当者）で絞り込み
- 基盤技術の画面には、その基盤に関連するサービスへのリンクを表示
- **CSV エクスポート**: 1 サービス 1 行（領域・関連する基盤技術は「、」区切り）。領域・メンバーの絞り込みを反映
- **CSV インポート**: サービス番号で照合して更新、なければ追加。更新時の空欄は元の値のまま。基盤番号は登録済みのみ。エラー行が 1 行でもあれば何も取り込まない。エクスポートしたファイルをそのまま（編集して）取り込める

## 共有資料（/documents）
共有資料へのリンク集。**左にグループ資料、右にその他参考資料**を表示（作成日時の新しい順）。
各資料は 1 行で表示: 資料名・領域（複数）・資料リンク最大 4 つ（それぞれ表示名つき）・作成日時・編集。目的は資料名にマウスを置くと表示。
- 各欄の「＋ 追加」／「✎」で登録・編集（欄の移し替えも可）。削除は編集画面から（パスワードが必要。リンク先の資料そのものは消えない）
- 資料名・目的・領域・リンクの表示名で検索、領域で絞り込み

## 参考リンク（/links）
左に「自社技術リンク」、右に「WEB リンク」（上: 自社サービス、下: その他参考）を表示するリンク集。
- 各リンク: 名前（クリックで新しいタブで開く）・URL・説明・領域（複数）。「＋ 追加」／「✎」で登録・編集（欄の移動も可）、↑↓ で並べ替え
- 削除は編集画面から（パスワードが必要）。名前・説明・URL・領域で検索、領域で絞り込み

## 管理サイト（/admin）
領域・案件番号・基盤番号・顧客の登録／修正／削除と、PJ名（案件番号＋基盤番号）の一覧。
項目にマウスを置くと使用状況を表示。名前を修正すると、使用中のタスク・案件・基盤の目標なども新しい名前に書き換わる。使用中の項目は削除できない。ガントチャート・案件管理の画面には管理ボタンは置かない。

### バックアップ・復元（管理サイトの一番下）
- **全データ**（ガントチャートのタスク・案件と週次メモ／月報・基盤の情報／目標／ディスカッション／月報・選択肢）を 1 つの JSON ファイルでダウンロード
- 「ファイルから復元」でバックアップの内容に全データを置き換え（パスワード必須）。データがすべて消えた状態からでも元に戻せる
- 復元の直前の状態はサーバーに自動保存（「復元前」）されるので、復元をやり直せる
- サーバーには月 1 回（直近 12 か月分）と、アプリの起動（アップデート）のたび（直近 10 回分）に自動でバックアップを保存。「サーバーに保存」で手動保存も可。一覧からダウンロード・復元・削除（パスワードが必要）ができる
- 古いバージョンのバックアップも新しいアプリに復元できる（足りない列は自動で補う）
- コマンドでも操作できる: `docker compose exec gantt python manage.py backup|restore|status`
- サーバー上のバックアップはデータフォルダ内（コンテナの `/data/backups`、Linux 設定ではホストの `data/backups`）にある。定期的に別の場所にも保管すること

## ログイン
- すべての画面・API はログインが必要（共通パスワード。`.env` の `APP_PASSWORD` で設定。未設定なら起動時に仮のパスワードをログ（`docker compose logs`）に表示）
- ログインの有効期間は 7 日。右上の「ログアウト」でログアウト
- パスワードを変更するには `.env` の `APP_PASSWORD` を変えて `docker compose up -d`（既存のログインは無効になる）
- https で公開する場合は環境変数 `COOKIE_SECURE=1` を設定
